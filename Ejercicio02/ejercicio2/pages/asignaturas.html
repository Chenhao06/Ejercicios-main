Módulos de ASIX

Qué aprenderás durante el primer curso de Administración de Sistemas Informáticos en Red.

Aprendizajes del curso

El ciclo combina fundamentos técnicos y competencias profesionales. Aprenderás a crear soluciones accesibles, trabajar con datos de forma organizada y resolver problemas con lógica.

Sistemes

Desarrolla el pensamiento algorítmico y la capacidad de escribir programas. Practica estructuras de control, datos y resolución de problemas mediante código.

Lenguajes de marcas y sistemas de gestión de información (LM)

Aprende a estructurar documentos con HTML y a presentarlos con CSS. También conocerás formatos de intercambio de datos y principios de accesibilidad web.

Bases de datos (BBDD)

Diseña modelos de datos y almacena información de manera coherente. Practica consultas y operaciones para gestionar datos con fiabilidad.

Sistemas informáticos (SI)

Explora componentes, sistemas operativos y redes. Adquiere una base para configurar y mantener el entorno de desarrollo.

Entornos de desarrollo (ED)

Utiliza herramientas para crear y probar software. Trabaja con depuración, control de versiones y documentación de proyectos.

Inglés profesional (IP)

Amplía el vocabulario técnico y la comunicación en inglés. Practica la comprensión de documentación y situaciones del ámbito laboral.

Itinerario personal para la empleabilidad I (IPE I)

Desarrolla habilidades para la incorporación al mundo profesional. Conoce derechos laborales, prevención de riesgos y herramientas para planificar tu itinerario.

Digitalización aplicada a los sectores productivos (DIG)

Conoce tecnologías y procesos de transformación digital. Relaciona estas herramientas con los cambios que experimentan las empresas.
